# FINISZ. / sprzątanie po remontach i budowie

Strona HTML/CSS/JavaScript bez instalacji. Wgraj całą zawartość `dist` do katalogu głównego repozytorium GitHub Pages, zachowując folder `assets`.

Oprawa techniczna: grafit, jasny beton, pomarańcz i robocza fotografia. Oferta obejmuje przykładowe doczyszczanie po remoncie, domy i lokale oraz przeszklenia. Bąbelki i miękka oprawa poprzedniej wersji zostały usunięte.

Efekt scroll scrubbing odsłania wnętrze jak przejazd ściągaczki. Suwak działa także klawiaturą. Efekt przed/po porównuje ostrą fotografię z dopasowanym wariantem z cyfrowo dodanymi odpadkami, nie dokumentuje realizacji. Przy ograniczeniu ruchu sekcja jest statyczna i obsługiwana suwakiem. Działają też reveal sekcji, płynny pasek, przełączanie usług i formularz z przeniesieniem wybranej usługi.

Formularz tworzy lokalne podsumowanie. Nie wysyła wiadomości, nie rezerwuje terminu i nie podaje automatycznej wyceny. Firma, oferta i lokalizacja są fikcyjne.

Fotografie ilustracyjne Unsplash: photo-1581578731548-c64695cc6952, photo-1600585154340-be6161a56a0c, photo-1600210492486-724fe5c67fb0. Google Fonts: Barlow Condensed, DM Sans, Manrope.

## Czytelność i porównanie
Powiększono opisy, nawigację, etykiety, przyciski, stopkę i formularz. Przed/po używa ostrej fotografii wnętrza i wariantu z odpadkami dodanymi cyfrowo; bez rozmycia. Wariant przed: assets/before-cleaning.png, utworzony wbudowanym imagegen na bazie assets/home.jpg. Prompt: preserve exact room geometry, camera and lighting, add renovation cleanup clutter such as empty cans, cardboard, paper and protective plastic, sharp realistic photo, no blur. Porównanie jest ilustracyjne.
